# T547 — La grana del suolo, le foto

Preview della build (`?skip&offline`, il seme), camera di base 3/4, l'inizio. Il seme non ha terreni con la grana: dalla console il
sentiero `p` ha preso il nome «brecciolino» (la riparazione dal nome: ghiaia chiara) e il prato `g` una grana detta
(`{ color: '#b0662c', density: 0.2 }`, foglie secche), poi le mesh dei luoghi rifatte.

1. `1-prima.jpg`: il suolo di prima, un colore per casella.
2. `2-con-la-grana.jpg`: le macchie sul prato e sul sentiero; nessun triangolo in più (la mesh ha solo l'attributo `grain`).
3. `3-dettaglio.png`: le macchie di un voxel (1/20 di casella), più chiare o più scure, sul sentiero e sul prato.
4. `4-tolta.jpg`: tolta la grana, il suolo è di nuovo quello di prima (materiale `MAT.world`, nessun attributo).

Le macchie arancioni del prato a una densità del 20 % lo fanno sembrare meno saturo da lontano: è la media del colore, voluta (foglie su erba).
