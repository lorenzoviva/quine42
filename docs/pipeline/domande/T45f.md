### 2. Architettura di hosting preferita
Il server di QUINE42 mantiene WebSocket attive per la sessione di gioco (`/api/session`) e repository git locali in `universes/`.
Quale modello architetturale preferisci adottare?
- **(a) Cloud Run**: container stateless con istanza minima 1 (`--min-instances=1`, timeout WebSocket fino a 60 min, session affinity abilitata) e volume montato Cloud Storage FUSE o disco persistente su NFS (Filestore) per `universes/`.
- **(b) Compute Engine VM** (es. `e2-small` o `e2-medium` con Debian/Ubuntu): istanza fissa con Docker Compose e persistent disk nativo per `universes/`, esposta con IP statico o dominio, più semplice per WebSocket continuative e git su disco locale.
